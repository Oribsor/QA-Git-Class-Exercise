# QA-Git-Class-Exercise

Class exercise repository for **Module 6: Git & GitHub for Software Testers**.

## מה יש כאן? (What's in here?)

| File / Folder | Purpose |
|---|---|
| `team.md` | Every student adds their name here (Steps 3-6 of the exercise) |
| `conflict.md` | Used for the merge-conflict exercise (Step 7) |
| `sample_tests/` | Sample test code - add your own test case here |

## Rules

1. Never work directly on `main` - always create your own branch.
2. Branch naming: `student/<your-name>` (example: `student/dana`).
3. Merge only through a Pull Request, after a review from a classmate.
